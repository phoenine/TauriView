# 离线词典

划线后点击词典图标，查看本地释义。汉语及成语默认使用简体，显示数据源收录的拼音；多音字可切换读音。成语的出处、例句等资料按需展开。可将查询结果保存到原划线的批注，也可主动交给 AI 结合上下文理解。查词本身不调用 AI 或第三方接口。

## 内置数据

- [mapull/chinese-dictionary](https://github.com/mapull/chinese-dictionary)：汉语词语、常用单字分读音释义、成语及出处。选择它是因为数据包含词语拼音与简体释义，不依赖按单字猜测词语读音。它是社区汇编，上游声明 MIT；完整来源说明保留在包内 `mapull.README`，不代表官方辞书授权或人工核校。
- [ECDICT](https://github.com/skywind3000/ECDICT)：英文音标、英汉／英文释义及词形变化，MIT。默认选取 BNC/FRQ 前 30000、考试标签、Collins 或 Oxford 核心词，控制内置包体积。
- [OpenCC](https://github.com/BYVoid/OpenCC)：构建时统一汉字显示为简体，Apache-2.0。导入的用户词典保留原内容。

曾考察教育部国语辞典、成语典：原资料以繁体为主，不作为简体产品的默认词库。商务印书馆有官方 App／授权产品，但此次未找到公开可直接内置的离线数据授权。Kaikki 中文维基词典的完整数据较大，未选为默认包。

这些开源汇编可能含错字、旧义或拼音错误。应用显示来源，批注保存词条、读音、释义及来源快照，方便追溯；没有用 AI 自动改写词典内容。

## 通用词典包

支持 UTF-8 StarDict 2.4.2／3.0.0：`.ifo`、`.idx` 或 `.idx.gz`、`.dict` 或 `.dict.dz`，以及可选 `.syn`。支持 32／64 位索引、文本、音标及转为纯文本的 HTML／XDXF；音频、图片字段不展示，不执行词条脚本或加载外链。

在“设置 → 词典”选择类别并导入。先解压下载的压缩包；桌面版选择 `.ifo`，程序读取同目录配套文件并复制到应用数据目录；浏览器开发版需一起选择配套文件，存入 IndexedDB。设置可分别停用／启用词典。当前不支持 MDX／MDD。

桌面版把内置资源随应用打包，首次查询建立本地解压缓存，后续按词条偏移读取。升级时依据 `.ifo` 更新缓存。浏览器开发版从本地开发服务器加载并缓存本次会话使用的词库；它不是跨重启离线的 PWA。

## 构建与检查

运行 `python scripts/fetch-dictionary-sources.py` 下载并缓存选定上游数据，然后运行 `python scripts/build-dictionaries.py` 生成 `resources/dictionaries` 中通用 StarDict 包。下载脚本跳过已有缓存；更新数据需有意替换缓存。每包包含来源、源数据校验摘要和许可证。`.dict.dz` 使用带 RA 字段的 dictzip，支持其他兼容阅读器。

验证包括 StarDict 边界和别名、内置真实词条、英文词形、多音字、简体成语、离线查词、批注位置保持、导入、停用、词条 HTML 惰性处理及主动 AI 交接。原始下载缓存不进入版本控制。
