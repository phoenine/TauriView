AI 理解

用于阅读时的「AI 理解」「举个栗子」和批注补充。任何 OpenAI 兼容的对话接口都能用；本机模型（如 Ollama）把地址填成 http://localhost:11434/v1，Key 可留空。

接口地址
不含 /chat/completions，例如 https://api.deepseek.com/v1
API Key
只保存在本机 localStorage，不会上传到任何第三方
模型
要和服务商给出的模型名一致
连接测试
发一条最小请求，确认地址、Key 与模型都可用

本地词典

词典查询完全离线。

导入 StarDict 词典
支持 .ifo、.idx / .idx.gz、.dict / .dict.dz 和 .syn；先解压下载的词典包。

内置汉语和成语词典使用简体释义，拼音采用词条收录的读音。来源与授权见词典包的说明文件。

听书
